# FORMA

Тёмный интерактивный сайт с 3D-кубиком Рубика.

[Открыть сайт](https://forma-cube-studio.ilha-tarasow.chatgpt.site)

## Управление

- Тяните квадратики мышью или пальцем, чтобы вращать нужный слой, включая средние ряды. Слой следует за движением.
- Тяните свободный фон, используйте правую кнопку мыши или Alt + перетаскивание, чтобы осмотреть кубик.
- Включите подсказки: камера покажет нужную грань, а стрелка укажет направление следующего поворота.
- Кнопки R, L, U, D, F, B поворачивают грани. Shift + буква — обратный поворот.
- Перемешивание, отмена хода, таймер, настройка скорости и сохранение сборки в браузере.

## Запуск

Это статический сайт без сборки. Для локального запуска:

```sh
python -m http.server 8080
```

Откройте http://localhost:8080. Для GitHub Pages выберите Settings → Pages → Deploy from a branch → main → /(root).

## Технологии

Three.js (MIT), cubejs (MIT), Web Worker для решения кубика. Лицензии сторонних библиотек включены в репозиторий. Анимации учитывают prefers-reduced-motion.
